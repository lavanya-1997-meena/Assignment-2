# Assignment-2
Driven Stock Analysis
Stock Driven Analysis is a data analytics project developed to analyze and understand the performance of Nifty 50 stocks using stock market data.
The project focuses on collecting, cleaning, processing, and analyzing stock data such as open, close, high, low, volume.
The analyzed data is used to:
 # Identify top-performing stocks
 # gainers & losers
 # sector-wise performance
 # monthly trends
 # cumulative return
 # volatility return
 # correlation between stocks

 Using Python, Pandas, MYSQL, Power BI, Stream lit for data processing, analysis, database management, and interactive visualization.

 The main goal of the project is to  understand stock market trends through data and visualizations.
